# Замер скорости скачивания

Требуется Python 3.10 или новее. Используется только стандартная библиотека, устанавливать зависимости не нужно.

## Запуск

Передайте прямую ссылку на файл:

```powershell
python test_script.py "https://images.pexels.com/photos/4869141/pexels-photo-4869141.jpeg"
```

Справка: `python test_script.py --help`.

## Расчёт

Скрипт выполняет 10 последовательных запросов и полностью читает каждый ответ блоками по 64 КиБ. Файл не сохраняется на диск. Считаются реально прочитанные байты тела ответа.

- Среднее время запроса = сумма длительностей / 10, в секундах.
- Общий объём = сумма прочитанных байтов.
- Скорость = общий объём / сумма длительностей / 1 048 576, в МиБ/с (1 МиБ = 1 048 576 байт).

Время включает подключение, ожидание ответа и чтение тела. Вывод в консоль в замер не входит. Результат зависит от сервера и сетевых задержек и не является точным измерением предельной скорости интернет-канала.

Таймаут сетевых операций — 30 секунд; это не общий лимит времени скачивания. При ошибке скрипт останавливается с кодом 1 без итоговой статистики за неполные 10 запросов. Некорректные аргументы приводят к коду 2; успешное завершение — код 0.
